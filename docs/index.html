FLUX.1 MMDiT Architecture

Multimodal Diffusion Transformer architecture designed for text-to-image synthesis

🔀

Dual-Stream MMDiT

19 joint transformer blocks allowing simultaneous bidirectional cross-attention between 4096-dim T5 prompt embeddings and 64-channel latent image patches.

⚡

Single-Stream Blocks

38 concatenated transformer blocks where text tokens and image patch tokens fuse into a single self-attention sequence for unified multimodal diffusion.

📐

3D RoPE Coordinates

Multi-dimensional Rotary Position Embeddings split across axes [16, 56, 56] encoding spatial row, column, and frame positioning.

🌊

Flow-Matching Euler

Command Line Usage

Fast, scriptable CLI built directly into the binary

bash - mflux CLI 
# Generate with FLUX.1-schnell in 4 steps
mflux generate --prompt "A cinematic shot of a cyberpunk city in rain" --model schnell --steps 4

# Generate with FLUX.1-dev with guidance scale 3.5
mflux generate --prompt "Studio portrait of an astronaut on Mars" --model dev --steps 25 --guidance 3.5 --output mars.png

# Benchmark step latency on Apple Silicon Metal
mflux bench --model schnell --steps 4

# Inspect model parameters and memory footprint
mflux info --model dev
